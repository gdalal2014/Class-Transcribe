ClassScribe

Privacy policy

Effective 18 October 2026.

ClassScribe is a personal Windows program, written by Gulzar Dalal for his own use, that records online classes, transcribes them and keeps a copy of each class in the user's own Google Drive. It runs entirely on the user's computer. It has no server, and nothing it handles is sent to its author.

Google user data it accesses

ClassScribe asks for one Google permission, https://www.googleapis.com/auth/drive.file. With it, ClassScribe can access only:

  • the files and folders that ClassScribe itself creates in the user's Google Drive, and their names, sizes, checksums (MD5) and identifiers;
  • the signed-in account's display name and email address, and its storage limit and usage.

It cannot see, read or change any other file in the user's Drive.

How it uses that data

  • To create a ClassScribe folder in the user's My Drive, with folders for each course and class date, and to upload the user's own class recordings, transcripts and logs into them.
  • To check that each uploaded file arrived whole, by comparing its size and MD5 checksum with the copy on the laptop.
  • To show the user which account is signed in and how much Drive storage is left.

ClassScribe never deletes or trashes anything in Google Drive. The only change it makes to a file already there is a new version of one of its own text files, such as a log that has grown.

Storage and protection

The Google sign-in (OAuth tokens) and the app's Google client details are kept only on the user's computer, in the user's own Windows profile, encrypted for the user's Windows account with Windows' Data Protection API. They are sent only to Google, over HTTPS, and are never written to logs. A record of what was uploaded (file names, sizes, checksums and Drive identifiers) is kept in the user's local application data so that nothing is uploaded twice.

Sharing

ClassScribe does not share, sell or transfer Google user data to anyone. It does not use it for advertising, and does not use it to develop, improve or train artificial intelligence or machine learning models. No Google user data is sent to the author or to any server other than Google's.

Separately from Google: to make a transcript, ClassScribe sends the class audio recorded on the user's computer to ElevenLabs, a speech-to-text service. That audio comes from the computer, not from Google Drive, and no data received from Google APIs is sent to ElevenLabs.

Limited Use

ClassScribe's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Ending access and deleting data

  • Signing out in ClassScribe (menu choice 9, then O, or ClassScribe drive signout) revokes its access with Google and deletes the sign-in from the computer.
  • Access can also be removed at any time from the Google Account's third-party connections page.
  • Files ClassScribe uploaded belong to the user and stay in the user's Drive until the user deletes them there.

Changes and contact

Any change to this policy will be published on this page with a new effective date. Questions can be raised as an issue on the project's GitHub page.
